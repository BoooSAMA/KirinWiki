# 实习生工作分析 — GMM Technoworld 技术支持助理

> **撰写目的**：基于公司背景深度分析，"推演"技术支持助理实习生的最可能工作内容，帮助候选人（冯一朗）提前做好心理预期和技能准备。
>
> **分析方法**：公司规模（4-10人）× 业务模式（贸易→PaaS转型）× 岗位JD × 行业特性 → 推演最可能的工作分配

## 核心判断：你会成为"所有人的手"

GMM 是一个微型企业。这意味着：

- **没有"专人专岗"的奢侈** —— 每个人都必须多面手
- **没有"慢慢培训"的时间** —— 你需要快速上手、直接产出
- **没有"这不该我做"的边界** —— 从搬货到写代码，从打扫到见客户，都可能是你的事

在这个前提下，以下是按**发生频率**排序、你最可能从事的工作内容。

---

## 一、最高频日常（每天/每周都会做的事）

### 1. 📦 IoT 设备测试与配置 —— 40% 的工作量

这是最核心的工作。GMM 的核心产品是 UbiBot 和 Kaiterra 的 IoT 传感器，这些设备**出货前必须经过测试和配置**。

**具体工作内容：**

| 任务 | 频率 | 详情 |
|------|------|------|
| 传感器开机测试 | 每天 | 拆箱 → 通电 → 确认 LED 指示灯正常 → 连接 WiFi → 确认数据上传云端 |
| WiFi/4G 网络配置 | 每天 | 使用 UbiBot App 将传感器连接到客户提供的 WiFi 网络；配置 4G 网关 APN 参数 |
| 固件检查与更新 | 每周 | 检查设备固件版本，必要时更新到最新版 |
| 数据校准/对比验证 | 每周 | 将传感器读数与参考标准对比，记录偏差值 |
| 电池/电源测试 | 每周 | 确认电池续航、电源适配器工作正常 |

**为什么占最大比重？**
因为 GMM 的核心商业模式是 **"卖设备 + 卖服务"**，设备如果到了客户手上出问题，售后成本极高。所以出货前的 QA 是生命线。而小公司不可能让技术经理整天做这些重复性工作，必然交给实习生。

### 2. 📋 产品入库质检（IQC）—— 20% 的工作量

GMM 从 11+ 个国家直接进口 2,000+ 种产品。每批货到都需要做质量检查。

**具体工作内容：**

| 任务 | 详情 |
|------|------|
| 开箱核对 | 按照装箱单清点数量，检查外观有无运输损坏 |
| 规格核对 | 把实物铭牌参数对照 datasheet 逐一核对（量程、精度、供电电压等） |
| 功能抽检 | 随机抽取一定比例的仪器进行通电功能测试 |
| 记录归档 | 填写 IQC 报告，拍照记录异常情况 |
| 问题上报 | 发现批次性问题时，整理证据提交给技术经理/供应商 |

**GMM 的品类复杂度决定了这个工作量大：** 温度计、湿度计、PM2.5 检测仪、噪音计、照度计、EMF 检测仪、风速计、水质检测仪……每个品类有不同的测试方法和标准。你需要在短时间内熟悉几十种不同类型的仪器。

## 二、中频工作（每周/每两周出现）

### 3. 🔧 现场安装与调试支持 —— 15% 的工作量

当 GMM 的客户下单了 EDSS™ 系统（多传感器部署），就需要**去客户现场安装**。

**典型场景：**

- **仓库温湿度监控部署**：在货架区安装 5-20 个 UbiBot 传感器，配置网关，确认所有设备数据上传到云端
- **数据中心环境监控**：在机柜上下安装温度传感器，配置超温报警阈值（短信/邮件推送）
- **办公室 IAQ 监测**：安装 Kaiterra Sensedge，连接公司 WiFi，配置展示大屏
- **学校/医院项目**：配合 BCA 绿建要求，部署环境监测网络

**实习生在现场的角色：**
- 搬设备和工具
- 在技术经理指导下安装传感器（贴墙固定、扎带固定等）
- 使用手机 App 逐一配对设备
- 记录安装位置和设备 ID 对应表
- 客户培训时在旁边学习，后续可能独立完成简单安装

> 💡 **重要提示**：这份工作涉及**爬梯子、走天花板线槽、进入机房/配电室、在仓库里穿梭**。这不是坐办公室的实习。穿适合干活的衣服和鞋子。

### 4. 📊 技术文档编写 —— 10% 的工作量

小公司没人专门写文档，但文档又必须有人写。

**你可能会被要求写：**

| 文档类型 | 样例 |
|----------|------|
| **产品对比表** | "Tenmars TM-196 vs CEM DT-9881 参数对比" —— 销售部需要这种资料来报价 |
| **简易操作指南** | "UbiBot WS1 快速设置指南（中文版）" —— 很多客户是中文用户 |
| **验收报告** | 项目安装完成后的客户签收文件 |
| **QC 记录** | 每批次产品的检测记录 |

**写这些文档的核心工具：** Microsoft Excel 和 Word。不是 markdown，不是 GitHub。这家公司不是科技公司，是贸易+解决方案公司。

## 三、低频但重要的工作（每月/按需）

### 5. 🎯 产品演示支持 —— 5% 的工作量

GMM 提供 **免费上门演示 + 两周试用** 的销售策略。这意味着：

- 销售团队去客户那里做演示时，你需要提前准备好演示样机（充满电、恢复出厂设置、放在演示箱里）
- 有时需要陪同前往，回答技术问题
- 演示结束后取回设备，检查状态，为下一次演示做准备

### 6. 📞 售后技术支援（电话/邮件）—— 5% 的工作量

客户买了设备后，可能遇到：
- "为什么传感器连不上 WiFi？"
- "App 上显示离线是怎么回事？"
- "数据在仪表盘上看不到，怎么办？"

**你的角色：** 处理第一线的基础问题。解决不了的上报技术经理。你在处理这些问题的过程中，会积累越来越强的 troubleshooting 能力。

### 7. 🏪 线上店铺运营协助 —— 3% 的工作量

GMM 有 testmeter.sg 和 waterproofgadget.biz 两个线上商店。你可能需要：
- 上传新产品图
- 更新产品描述和规格
- 回复客户在线咨询

这虽然不是"技术支持"，但在小公司里，你很可能需要支援一下。

### 8. 🎒 展会/活动支持 —— 2% 的工作量

GMM 可能参加行业展会（如 BuildTech Asia、Singapore Green Building Week 等）。你需要：
- 帮忙打包样品和设备
- 展会现场看管展台
- 向参观者简单介绍产品

## 五、你需要特别注意的"隐藏工作"

这些是 JD 上不会明写，但你几乎一定会遇到的事情：

### 1. 仓库/库存管理
GMM 有 2,000+ SKU，仓库管理本身就是一个不小的工作量。你可能会被叫去整理货架、盘点库存、打包发货。这不是"技术工作"，但在小公司里无法避免。

### 2. 跨语言沟通
GMM 从 11 个国家进口，供应商讲中文、英文、韩文、日文……客户的官方语言有英文，但实际操作人员可能只说中文。你的中英双语能力在这里会很有用。

### 3. 自己"搞定事情"的能力
在一家 4-10 人的公司里，没有人手把手培训你。设备怎么用？—— 看说明书自己学。App 怎么配？—— 自己下载自己试。遇到问题怎么办？—— 先自己 Google/百度，实在不行再问。**主动学习和独立解决问题的能力，比任何技术背景都重要。**

### 4. 随时可能被叫去做"杂事"
这不是贬义。在小公司，每个人都可能：
- 帮忙搬货
- 帮忙打包快递
- 帮忙打扫展台
- 帮忙跑腿送文件

**正确的心态**：这些事不是"浪费"，而是你了解公司运作全貌的机会。同时也是建立信任的方式。
