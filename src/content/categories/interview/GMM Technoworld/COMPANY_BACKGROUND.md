## 3. EDSS™ (Environmental Detecting Systems Solutions) — Core Product

### What is EDSS™?

GMM's smart industrial workplace system that integrates IoT sensors, cloud platforms, and alert systems for real-time environmental monitoring. Think of it as a **building/site-wide sensor network** that detects environmental parameters and triggers alarms.

### Key Capabilities

| Feature | Description |
|---|---|
| **Real-time Monitoring** | Continuous sensing of temperature, humidity, air quality (PM2.5, CO2, TVOC), light, vibration |
| **Cloud Data Logging** | Auto-sync, unlimited storage on secure cloud platform |
| **Remote Access** | View real-time + historical data via mobile app (UbiBot) or web console |
| **Instant Alerts** | App push, email, SMS, phone call when parameters exceed thresholds |
| **Data Analysis** | Historical trends, custom reports, analytics dashboard |
| **Connectivity** | WiFi, 4G cellular — flexible deployment options |
| **Integration** | Potential integration with BMS (Building Management Systems) |

### Hardware Partners (Key OEMs Integrated)

| Brand | Product Category |
|---|---|
| **UbiBot** | Smart IoT WiFi/4G temp + humidity sensors (WS1, GS1-A) |
| **Kaiterra** | Indoor Air Quality (IAQ) monitors (Sensedge) |
| **Tongdy** | Commercial-grade IAQ monitors (EM21 Series — PM2.5, CO2, TVOC) |
| **Tenmars** | Measuring meters |
| **CEM** | Measurement meters |
| **HM Digital** | Water quality meters |
| **CORNET** | EMF/ElectroSmog meters |

### Target Use Cases

- Warehouse environmental monitoring (temperature, humidity for goods protection)
- Data centre temperature and humidity tracking
- Manufacturing facility IAQ compliance (WELL V2, LEED V4)
- Cold chain / food storage monitoring
- Office IAQ for staff wellness
- Green building compliance (Singapore BCA Green Mark)

### Service Model

- Free on-site demo with loaner device (up to 2 weeks)
- Personalised consultation and tailored system design
- Setup, installation, commissioning
- After-sales technical support and maintenance
