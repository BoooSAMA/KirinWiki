- [ ] **岗位职责**：产品开发 > 软件开发 > 演示汇报 > 测试（记住优先级）

### 💻 技术准备

- [ ] **C# 核心概念复诵**（对着镜子说，每条控制在 1-2 分钟）：
  - [ ] Class vs Struct（引用类型 vs 值类型，GC 影响，Unity 中 Vector3 为什么是 Struct）
  - [ ] GC 工作原理（Gen 0/1/2，VR 90FPS 下如何避免 GC spike）
  - [ ] async/await vs Unity Coroutine（区别、UniTask、ConfigureAwait）
  - [ ] Interface vs Abstract Class（什么时候用哪个，给具体例子）
  - [ ] Observer 模式 / Event System（解耦、Unity 中 ScriptableObject 事件）
  - [ ] IEnumerable vs List、LINQ 陷阱（延迟执行、Update 里别用 LINQ）
- [ ] **C# 快问快答**：
  - [ ] `using` 语句
  - [ ] `const` vs `readonly`
  - [ ] Delegate、Action vs Func
  - [ ] Generic constraint
  - [ ] String vs StringBuilder
  - [ ] NullReferenceException 预防
- [ ] **Unity 基础**（不要求项目经验，但至少能说）：
  - [ ] MonoBehaviour 生命周期（Awake → OnEnable → Start → FixedUpdate → Update → LateUpdate → OnDisable → OnDestroy）
  - [ ] ScriptableObject 是什么、为什么用它
  - [ ] Prefab、Scene、GameObject-Component 模型
- [ ] **VR 性能优化**（能说出策略即可）：
  - [ ] 90 FPS = 11.1ms/frame 预算
  - [ ] CPU 端：Object Pooling、缓存 GetComponent、避免 Find()、Job System + Burst
  - [ ] GPU 端：Draw Call Batching、LOD、Occlusion Culling、Single-Pass Stereo
  - [ ] VR 特有：Fixed Foveated Rendering、ASW/Motion Smoothing、减少后处理
