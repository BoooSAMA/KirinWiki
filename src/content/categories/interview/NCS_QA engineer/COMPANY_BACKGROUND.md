## 3. Role: Quality Engineer Intern (6 Months)

### Position Summary

> Support the testing and quality assurance of software platforms, including systems related to **video analytics and video management**. This role provides hands-on exposure to software testing, troubleshooting, automation, and quality assurance practices within the software development lifecycle.

The intern will work closely with development and product teams to ensure software features and system integrations function correctly and meet business requirements. Suitable for students interested in software testing, automation, system validation, and application quality assurance.

### Core Responsibilities

| # | Responsibility | Weight | What It Really Means |
|---|---|---|---|
| 1 | **Review software requirements** and understand system functionality | ⭐⭐⭐ | Read specs/PRDs; clarify ambiguity; understand expected behavior before testing |
| 2 | **Create and execute test cases** for software applications | ⭐⭐⭐⭐⭐ | Write structured test scenarios covering normal, boundary, and error conditions; execute them systematically |
| 3 | **Functional testing, system validation, and defect tracking** | ⭐⭐⭐⭐⭐ | Black-box + white-box testing; log defects in tracking system (e.g., JIRA); verify fixes |
| 4 | **Identify, troubleshoot, and document software issues** | ⭐⭐⭐⭐ | Root cause analysis; reproduce bugs; write clear defect reports with steps to reproduce |
| 5 | **Prepare test reports and document test results** | ⭐⭐⭐ | Summarise testing outcomes; track pass/fail metrics; communicate status to team |
| 6 | **Support automation and scripting** (Python, Bash, PowerShell) | ⭐⭐⭐⭐ | Write/maintain test automation scripts; automate repetitive testing tasks |
| 7 | **Write basic SQL queries** for data validation and troubleshooting | ⭐⭐⭐ | Query databases to verify data integrity; validate backend state after test execution |
| 8 | **Gain exposure to Docker, Kubernetes, Linux, cloud platforms** | ⭐⭐ | Deploy test environments; run tests in containerised environments; basic cloud interactions |
| 9 | **Work with development and engineering teams** to improve quality | ⭐⭐⭐ | Participate in Agile ceremonies; collaborate on defect prevention and process improvement |

### Learning Objectives (What the Intern Will Gain)

1. Real-world software QA methodologies, testing processes, and best practices
2. Hands-on test automation and scripting in Python / Bash / PowerShell
3. SQL proficiency for backend data validation
4. Exposure to modern infra: Docker, Kubernetes, Linux, cloud platforms
5. Experience in a large-scale tech services environment (15,000+ employees)
6. Analytical, troubleshooting, and problem-solving skills in a live project environment

## 4. The Video Analytics & Video Management Domain (Key Context)

This role is specifically tied to **systems related to video analytics and video management**. Understanding this domain is crucial.

### NCS KAI Platform — Video Intelligence

NCS's flagship video analytics platform is called **KAI** (Knowledge AI), built in collaboration with NVIDIA:

| Component | Description |
|---|---|
| **KAI Marketplace** | Ready-made video analytics models for security, construction, manufacturing, healthcare, retail |
| **KAI Co-Create** | Tools for developers to build, train, and benchmark video analytics models (data annotation, model training, benchmarking) |
| **KAI Unified Platform** | Open platform integrating with existing cameras and VMS (Video Management Systems) |
| **KAI SnS** (Search & Summarisation) | AI-powered video search using NVIDIA NIM, VLMs, LLMs, RAG; agentic workflow for multi-agent investigation |

### What Video Analytics QA Involves

| Testing Area | What It Covers |
|---|---|
| **Detection Accuracy** | Does the model correctly detect objects/events? False positives? False negatives? |
| **Latency/Performance** | End-to-end processing delay from camera → analytics → alert |
| **Integration Testing** | Cameras → VMS → Analytics engine → Alerting system → Dashboard |
| **Data Pipeline** | Video ingestion → frame extraction → model inference → metadata storage |
| **UI/Dashboard** | Visualisation of analytics results, alert management, configuration |
| **Regression** | New model versions don't break existing detections |
| **Scale Testing** | How does the system behave with 10 vs 100 vs 1000 cameras? |

### Typical Tech Stack in Video Analytics QA

- **Tools**: OpenCV, FFmpeg (video processing)
- **Scripting**: Python (most common), Bash
- **Test Types**: Functional, integration, performance, regression
- **Infrastructure**: Docker containers for microservices, Kubernetes for orchestration
- **Data Validation**: SQL queries against metadata databases
